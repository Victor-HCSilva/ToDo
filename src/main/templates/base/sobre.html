Sobre este app

Este é um aplicativo simples de lista de tarefas (To-Do List) desenvolvido com o framework web Django, que segue o padrão Model-View-Controller (MVC) para uma estrutura robusta e escalável. Ele permite aos usuários criar, visualizar, editar, marcar como concluído e excluir anotações.

Para o frontend, foi utilizado o Tailwind CSS via Twind, um framework utility-first que facilita a criação de layouts bonitos e adaptáveis a diferentes tamanhos de tela.
